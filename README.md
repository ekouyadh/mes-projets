
# Mes projets

Mon portfolio présente deux projets informatiques :
- Mon site personnel
- Ma liste de tâches

## Installation

```bash
npm install
```

## Lancement

```bash
npm run dev
```

## Construction du projet

```bash
npm run build
```

## Utilisation des props

Le composant CarteProjet reçoit trois props :
- titre
- technologies
- description

Ces informations permettent d'afficher les détails de chaque projet.

## Utilisation de children

Le composant Encadre reçoit le contenu placé entre ses balises.
Ce contenu est accessible avec props.children.
